# Spotify Clone – Frontend Web Application

A frontend web application inspired by Spotify, developed to strengthen understanding of modern web fundamentals such as responsive UI design, client-side audio handling, and JavaScript-based DOM manipulation. The project focuses on implementing core user interactions and interface behavior commonly found in real-world media applications.

---

## Overview

This project replicates the **look and feel** of a music streaming platform using standard web technologies. It is designed as a learning-oriented implementation to explore how frontend components interact with user input and browser APIs, without relying on backend services.

---

## Key Features

* Responsive user interface inspired by Spotify
* Client-side audio playback using the HTML5 Audio API
* Play, pause, and seek functionality for tracks
* Dynamic song list rendering
* Interactive controls implemented using JavaScript event handling

---

## Technology Stack

* **HTML5** – Semantic markup and application structure
* **CSS3** – Layout design, responsiveness, and styling
* **JavaScript (Vanilla)** – DOM manipulation, event handling, and audio control

---

## Scope and Limitations

* Frontend-only implementation
* No backend services, authentication, or database integration
* Media content and playlists are statically defined

---

## Potential Enhancements

* Integrating a backend for user authentication and playlist management

* Improving accessibility and keyboard navigation
